# Fates Flipper

The in-game mod of the SkyBlock Market Intelligence Suite: a Fabric client mod for Hypixel SkyBlock
that shows flips from Fates Viewer in chat, opens auctions on a key press, and adds price tooltips.

**Display only.** The mod never clicks, buys, confirms or repeats actions for the player. Every
purchase is the player's own clicks.

Status: in planning. The interface with the viewer is documented in the project's
`contract-mod.md`.
